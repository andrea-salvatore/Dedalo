# Security Policy

## Supported Versions

Dedalo is currently in active early development. Security updates and patches are only evaluated and applied to the latest commit on the `main` branch. 

| Version | Supported          |
| ------- | ------------------ |
| Latest (`main`) | :white_check_mark: |
| Older commits   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you believe you have discovered a security vulnerability in Dedalo (e.g., related to Unity Gaming Services integration, authentication bypass, or data exposure), please report it to us privately and responsibly. 

You can report a vulnerability using one of the following methods:

1. **GitHub Private Reporting:** Use the "Security" tab on this repository, navigate to "Advisories", and click **"Report a vulnerability"**.
2. **Direct Email:** Send an email directly to the maintainer at **asalvatore.junior@gmail.com**.

### What to include in your report:
To help us resolve the issue quickly, please include:
* A detailed description of the vulnerability and its potential impact.
* Step-by-step instructions to reproduce the issue.
* Information about your environment (Unity version, OS).
* Any potential mitigation or solution if you have one.

### What to expect:
We take security very seriously. You can expect:
* An acknowledgment of your report within 72 hours.
* A timeline for when we expect to have a fix deployed.
* We will not disclose the vulnerability publicly until a fix has been pushed to the `main` branch.
